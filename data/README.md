# Data

`samples/` holds 8 test documents (PDF, DOCX, XLSX, PPTX; a two-column paper, a LaTeX-style paper
and a scanned PDF). `samples/expected/*.json` holds what each one should contain (headings, tables,
list items, paragraph anchors).

All text is **synthetic**: generated by `scripts/make_samples.py` and `scripts/make_latex_sample.py`,
so no real person's or company's data is included, and the expected content is exact.

Regenerate: `python scripts/make_samples.py && python scripts/make_latex_sample.py`

These files are a regression suite for the converter. They are not a benchmark of real-world
accuracy: see docs/03_evaluation.md.
